# Bundled font sources

- **Nunito** — Google Fonts, SIL Open Font License 1.1.
- **Noto Serif JP** — Google Fonts, SIL Open Font License 1.1.
- **Noto Sans JP** — user-supplied Google Fonts archive, SIL Open Font License 1.1.
- **Two Weekend Go** — user-supplied project archive; see `LICENSE-Two-Weekend-Go.txt`.
- **FOT-NewRodin Pro** — user-supplied FontGeek archives. No redistribution license was included in those archives. Confirm redistribution rights before publishing these files outside a private deployment.

The New Rodin and Two Weekend Go webfont files contain Latin-only subsets for interface use. The Noto Japanese webfonts retain their full supplied character coverage.
